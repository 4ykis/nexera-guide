# Nexera — довідник мандрівника

Односторінковий інформативний гайд по світу Nexera: суходоли, магія, боги, раси, дев'ятнадцять держав і класи Daggerheart. Побудований як self-contained HTML (стилі, шрифти й карта світу вбудовані в файл).

Джерела контенту — `Nexera/Info/NEXERA_PLAYER_GUIDE.md` та `Nexera/Info/DAGGERHEART_CLASSES.md` в основному проєкті.

## Перегляд

Відкрити `index.html` у браузері, або дивитись задеплоєну версію на GitHub Pages (посилання в описі репозиторію).
